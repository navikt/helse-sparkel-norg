# sparkel-norg [![Build](https://github.com/navikt/helse-sparkel-norg/actions/workflows/build.yml/badge.svg)](https://github.com/navikt/helse-sparkel-norg/actions/workflows/main.yml)

Formålet med sparkel-norg er å svare på behov/http-kall med data fra systemet Norg. Det gjelder i all hovedsak
geografisk tilhørighet.

## Historikk

Denne appen var tidligere en del av monorepoet [sparkel](https://github.com/navikt/helse-sparkelapper). Repoet er en
kopi av sparkelapper-repoet, så det er historikk (inkludert for de andre modulene i sparkelapper) tilbake til da koden
ble kopiert inn i sparkelapper. Den ble kopiert fra repoet som nå
heter https://github.com/navikt/helse-sparkel-norg-old.
